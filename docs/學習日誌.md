### 【今天的技術原理】Python 執行環境與 conda

**比喻**：Python 像一間廚房，套件（pandas、streamlit、plotly…）像廚具。如果你所有專案都擠在同一間廚房，A 專案要新版平底鍋、B 專案要舊版，就會打架。conda 讓你蓋好幾間「獨立廚房」（環境），每間有自己的 Python 版本和自己的廚具。

你在電腦上做過的事，逐行拆開：

```bat
conda create -n nba python=3.11      :: 蓋一間叫 nba 的新廚房，裡面放 Python 3.11
conda activate nba                   :: 走進這間廚房（終端機最前面會出現 (nba)）
pip install -r requirements.txt      :: 照著購物清單把廚具一次買齊
streamlit run app.py                 :: 在這間廚房裡開始煮（啟動網頁）
```

- `requirements.txt` 就是那張購物清單。你的清單上有 `streamlit`、`pandas`、`plotly`、`supabase`、`python-dotenv`、`openpyxl`、`nba_api`。Streamlit Cloud 部署時，也是照這張清單幫雲端那台電腦裝套件，所以**新增套件一定要記得加進這個檔案**，不然本機能跑、網站會壞。
- 為什麼 VS Code 右下角要選「nba」那個直譯器？因為 VS Code 要知道你要用哪一間廚房；選錯就會出現 `ModuleNotFoundError: No module named 'streamlit'`——意思是「這間廚房沒有這個廚具」。
- 小知識：今天我在雲端測試時，那台機器沒辦法安裝 streamlit，所以我做了「假的 streamlit」來模擬。這正好說明：程式能不能跑，跟「當下是哪個環境、裝了什麼」息息相關。

### 【今天新功能的程式拆解】

**1. 一頁一頁讀投籃紀錄（`load_shots`）**

```python
@st.cache_data(ttl=3600, show_spinner="讀取投籃紀錄中…（一季約 7,000 次出手）")
def load_shots(team_id, season, season_type):
    client = get_client()
    rows, start, page = [], 0, 1000
    try:
        while True:
            part = (client.table("shots")
                    .select("game_id,game_event_id,player_name,loc_x,loc_y,made,zone_basic,zone_area,shot_distance")
                    .eq("team_id", team_id).eq("season", season).eq("season_type", season_type)
                    .order("game_id").order("game_event_id")
                    .range(start, start + page - 1).execute().data)
            rows += part
            if len(part) < page:
                break
            start += page
    except Exception:
        return pd.DataFrame()
    return pd.DataFrame(rows)
```

- `@st.cache_data(ttl=3600, ...)`：讀過一次的結果記住 1 小時，同一隊同一季第二次看就不用再等。
- `rows, start, page = [], 0, 1000`：準備一個空串列裝資料；從第 0 筆開始；每次讀 1000 筆（Supabase 一次最多給 1000 筆）。
- `.select("game_id,...")`：只拿需要的欄位，不用 `*`，傳輸量少很多。
- `.eq("team_id", ...).eq("season", ...)`：**最重要的一行**。shots 有幾十萬筆，一定要先叫資料庫只給「這隊、這季、這種比賽」，不然會讀到天荒地老。
- `.order(...)`：分頁時一定要固定排序，不然第 2 頁可能和第 1 頁重複或漏掉。
- `.range(start, start + page - 1)`：第一次拿第 0～999 筆，第二次 1000～1999 筆……
- `if len(part) < page: break`：這一頁不滿 1000 筆，代表讀完了，跳出迴圈。
- `except Exception: return pd.DataFrame()`：資料表不存在或連線出錯時，回傳空表格，畫面就會顯示「尚未載入資料」而不是一片紅色錯誤。

**2. 把出手整理成「每區一列」（`zone_table` 的核心）**

```python
g = d.groupby(["zone_basic", "zone_area"], as_index=False)[["fga", "fgm"]].sum()
g["fg_pct"] = g["fgm"] / g["fga"].replace(0, pd.NA)
g["share"] = g["fga"] / g["fga"].sum()
g["value"] = g["zone_basic"].map(lambda z: 3 if "3" in z else 2)
g["pps"] = g["fg_pct"] * g["value"]
```

- `groupby([...]).sum()`：把「同一區」的出手加起來，例如「中距離（左翼）」出手 512、命中 205。
- `fg_pct`：命中率 = 命中 ÷ 出手；`.replace(0, pd.NA)` 避免除以 0。
- `share`：這區佔全部出手的比例，就是「每 100 次出手有幾次在這裡」。
- `value`：區域名稱裡有「3」（Corner 3、Above the Break 3）就是三分區，投進值 3 分，其他值 2 分。
- `pps`：每次出手平均得分 = 命中率 × 分值。**這一欄就是今天假設的關鍵**：中距離 45% × 2 = 0.90 分，三分 36% × 3 = 1.08 分。

<summary>答案</summary>

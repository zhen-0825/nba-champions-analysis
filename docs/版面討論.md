# 版面討論

每天由每日任務提出版面問題與建議。**使用者不在檔案裡回覆**：每日任務直接在對話中逐項詢問，選項是【是】【否】【其他意見】，回覆後由 Claude 寫進下表；「是」的隔天實作。最新的在最上面。

方向（使用者 2026-10-30 確定）：像維基百科一樣「有邏輯、讓人可以一直讀下去」，不是故事書。每頁開頭有摘要、結構一致、頁面之間互相連結、說明清楚但不冗長。
